**Run this script to install docker

```**
curl -sSL https://raw.githubusercontent.com/p-shubh/installation_scripts/main/universal/install.docker.sh | bash
```

**Run this script to install Caddy as a native package (systemd service, not Docker)

```
curl -fsSL https://raw.githubusercontent.com/p-shubh/installation_scripts/main/universal/install.caddy.package.sh | sudo bash
```
